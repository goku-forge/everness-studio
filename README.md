# Everness Studio

An **offline-first, zero-ads mobile IDE** for Android—run Python (with 86+ data science packages & Matplotlib plots), JavaScript, SQLite, HTML/CSS, Markdown, and CSV right on your phone.

Built by **GokuForge** (`gokuforge@gmail.com`).

---

## Features

- **Python 3 (Pyodide WASM):** Runs offline in a background Web Worker with **86+ pre-bundled packages** (`numpy`, `pandas`, `matplotlib`, `scipy`, `scikit-learn`, `sympy`, `networkx`, `pillow`, `beautifulsoup4`, `tabulate`, and more).
- **Matplotlib Plots + PNG Export:** Renders multi-figure 2D/3D plots directly in the output pane with pinch-to-zoom and one-tap **Save PNG**.
- **JavaScript Sandbox:** Fast Web Worker JS execution with clean console output.
- **SQLite Database:** Persistent SQLite engine backed by IndexedDB, plus a built-in table browser, schema viewer, and `.sqlite` import/export.
- **HTML / CSS / Markdown / CSV Live Preview:** Instant preview with **20 bundled offline JS libraries** (`Chart.js`, `Three.js`, `D3`, `p5.js`, `marked`, `Tone.js`, etc.).
- **Multi-Provider AI Copilot:** Bring your own API key for **Google Gemini**, **Anthropic Claude**, **OpenAI**, **OpenRouter**, or any custom OpenAI-compatible endpoint—with automatic model fetching and a **± Diff** code preview before applying fixes.
- **Mobile-First Editor:** CodeMirror with syntax highlighting, multi-file tabs with close buttons, regex/case/whole-word search across all files, Gboard clipboard support, snippets, landscape optimization, **8 accent themes**, and **AMOLED black** mode.
- **Built-In Terminal:** Supports `ls`, `cat`, `rm`, `touch`, `cp`, `mv`, `run`, `pip list`, `pip install`, `libs`, and Python REPL.

## Download & Install

1. Go to the **[Releases](https://github.com/goku-forge/everness-studio/releases/latest)** page.
2. Download the latest `EvernessStudio_*.apk`.
3. Open the APK on your Android device and allow installation from your browser/files app.

*(The app includes an in-app **Check Updates** button powered by GitHub Releases.)*
